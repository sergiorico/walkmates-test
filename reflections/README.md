# Lab reflections

Copy [`reflection-template.md`](../lab-instructions/reflection-template.md) into this directory
once per lab and name the completed files:

- `lab1-reflection.md`
- `lab2-reflection.md`
- `lab3-reflection.md`
- `lab4-reflection.md`

Keep the original template unchanged so both partners can reuse the same structure throughout
the course.
